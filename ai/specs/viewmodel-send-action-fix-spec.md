# ViewModel SendAction Fix

## Overview
Нужно внести правку в коде в крайних незаконченных изменениях.

## Requested Behavior
- Найти проблему, где во `ViewModel` используется не `sendAction` подход, а прямой вызов функций.
- Заменить прямой вызов функций на `sendAction` подход.
- Остальное не менять, так как всё остальное good.

## Acceptance Criteria
- В затронутой `ViewModel` больше нет прямого вызова функций там, где должен использоваться `sendAction`.
- Используется `sendAction` подход.
- Остальные изменения не затронуты.
