# Vacancy Application UI Polish

## Overview
Нужно поправить UI на экранах vacancy details, cover letter templates и profile.

## Requested Behavior

### Vacancy Details
- В щите подачи на вакансию сделать `Cover letter templates` более акцентным.
- Можно использовать подчеркивание или другой визуальный акцент.
- Убрать название вакансии из щита подачи на вакансию, так как оно там излишне.

### Cover Letter Templates
- Items на экране `cover letter templates` нужно визуально отделить друг от друга.
- Возможный подход: стиль похожий на вакансии, с серым фоном и белым ободком.
- Альтернативно можно использовать только белый ободок, если так будет лучше смотреться.

### Profile
- Добавить кнопку назад на `profile screen`, чтобы пользователь мог возвращаться назад.

### Template Alert
- Для alert создания, просмотра, редактирования template обновить layout actions.
- Убрать `Close` полностью.
- Alert должен закрываться по тапу вне alert.
- `Delete` перенести наверх справа.
- `Delete` заменить на иконку удаления, например корзинку.
- `Edit` и `Apply` оставить снизу в один ряд кнопок.
- `Edit` и `Apply` можно визуально выделить или отделить, но стиль должен соответствовать текущему UI приложения.
- Цвета alert привести к теме приложения: темный фон, белый текст.
- Текущий розоватый цвет alert некорректен.

## Explicitly Ignored
- Инструкцию про сердечки у favorites игнорировать.

## Acceptance Criteria
- В щите подачи на vacancy details `Cover letter templates` визуально акцентирован.
- Название вакансии больше не отображается в щите подачи на vacancy details.
- Items на `cover letter templates` экране визуально отделены друг от друга.
- На `profile screen` есть кнопка назад.
- Template alert не содержит `Close`.
- Template alert закрывается по тапу вне alert.
- `Delete` расположен наверху справа и отображается как иконка удаления.
- `Edit` и `Apply` расположены снизу в один ряд.
- Template alert использует темный фон и белый текст в стиле темы приложения.
