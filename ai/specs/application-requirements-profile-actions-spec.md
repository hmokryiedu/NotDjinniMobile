# Application Requirements Profile Actions

## Overview
Нужно исправить проблемы с подачей на вакансии, действиями в employer profile и иконкой создания вакансии на главном экране.

## Requested Behavior
- Запретить подачу на вакансии, если пользователь не метчится по требованиям вакансии.
- В employer profile заменить текущую кнопку `change role` на кнопку `edit profile`.
- Добавить кнопку `change role`, чтобы пользователь мог менять роль.
- На главном экране заменить иконку плюсика для создания вакансии на иконку без круга, которая сейчас используется в `cover letter templates`.

## UI Notes
- `employer profile`: вместо текущей `change role` должна быть `edit profile`.
- `change role` должна остаться доступной как отдельная кнопка для смены роли пользователя.
- Иконка создания вакансии на главном экране должна использовать вариант без круга из `cover letter templates`.

## Acceptance Criteria
- Нельзя податься на вакансию, если пользователь не метчится по требованиям.
- В employer profile отображается кнопка `edit profile` вместо текущей `change role`.
- В интерфейсе есть отдельная кнопка `change role` для смены роли пользователя.
- На главном экране иконка создания вакансии заменена на иконку без круга из `cover letter templates`.
