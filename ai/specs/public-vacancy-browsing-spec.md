# Public Vacancy Browsing

## Overview
Добавить возможность пользователям без авторизации и без логина посмотреть вакансии.

Пользователь может попасть в приложение из экрана авторизации через отдельное действие для просмотра вакансий. В этом режиме пользователь не является `seeker`, а работает как отдельный `public` пользователь.

## User Goal
- Пользователь без аккаунта или без текущей авторизации может быстро зайти и посмотреть доступные вакансии.
- Пользователь может позже вернуться на экран авторизации и авторизироваться.

## Requested Behavior
- На экране авторизации добавить кнопку или действие для входа в режим просмотра без авторизации.
- При выборе этого действия пользователь попадает в отдельный `public` режим.
- В `public` режиме пользователь видит основной список вакансий.
- В списке вакансий не должно быть рекомендованных вакансий.
- Пользователь может открыть `Vacancy Details` и посмотреть доступную информацию по вакансии.
- Пользователь не может податься на вакансию.
- Перехода на профиль в `public` режиме быть не должно.
- Дополнительные функции, которые не относятся к просмотру списка вакансий и деталей вакансии, должны быть недоступны.
- В топ-баре главного экрана вместо кнопки профиля должна быть кнопка логина.
- При нажатии на кнопку логина пользователь попадает на экран авторизации.
- При переходе на экран авторизации нужно очистить весь back stack, чтобы не оставались лишние экраны.
- После возврата на экран авторизации пользователь может авторизироваться обычным способом.

## UI Notes
- На экране авторизации действие для входа без авторизации может быть оформлено как кнопка или текст под текстовыми полями.
- Возможные варианты текста:
  - `View only`
  - `Authorize later`
  - другой похожий текст для входа без авторизации.
- В `public` режиме в топ-баре главного экрана нужна кнопка логина вместо текущей кнопки профиля.
- Для кнопки логина можно временно использовать любую подходящую иконку, похожую на дверь или вход. Иконка будет заменена позже.

## Acceptance Criteria
- Неавторизованный пользователь может перейти с экрана авторизации в `public` режим.
- В `public` режиме открыт основной список вакансий.
- В `public` режиме не отображаются рекомендованные вакансии.
- В `public` режиме недоступен переход на профиль.
- В `public` режиме можно открыть детали вакансии.
- В `public` режиме нельзя податься на вакансию.
- В `public` режиме топ-бар показывает кнопку логина вместо кнопки профиля.
- Нажатие на кнопку логина открывает экран авторизации.
- При переходе к авторизации очищается back stack.
- После возврата на экран авторизации пользователь может авторизироваться.
